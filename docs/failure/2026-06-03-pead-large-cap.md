# 실패 기록: 실적발표 후 주가 표류(PEAD) — 대형주 유니버스

- **작성일**: 2026-06-03
- **브랜치**: `feature/earnings-pead`
- **관련 계획**: `docs/plan/2026-06-03-earnings-pead.md`
- **판정**: ❌ 실패 (대형주 KOSPI에서 거래 가능한 엣지 없음). 자본 투입 전 모드 A에서 종료.

## 한 줄 요약

"좋은 실적 발표 종목을 따라 사서 기댓값에 판다"는 PEAD 가설을, **신호 3계열(절대 YoY 수준 / 이익-주가 갭 / SUE 서프라이즈)** 로 대형주 10종목·2016~2024·DART 데이터에서 검증한 결과 **비용 차감 전에도 양의 알파가 없었고, 정통 SUE 신호는 오히려 음수(되돌림)** 였다. 실제 매매 로직(모드 B)은 구현하지 않고 측정 단계(모드 A)에서 정직하게 종료.

## 무엇을 어떻게 검증했나

엔진(단일 포지션)으로 다종목 PEAD를 흉내내면 거짓 수익률이 나오므로, **백테스트 없이 시장조정 누적초과수익(CAAR)** 으로 알파 존재를 먼저 본 것(모드 A). 룩어헤드 차단: 공시 접수일 다음날부터 누적, p-해킹 차단: IS(In-Sample) 탐색 → OOS(Out-of-Sample) 1회 확인.

| 신호 | 본질 | 결과 |
|------|------|------|
| EPS YoY ≥ 20% | "많이 컸나"(성장 수준) | 전 지평선 \|t\|<2, 유의 알파 없음 |
| 복합 YoY 스윕(40종) | 결합/임계 탐색 | IS 10/40이 \|t\|>2였으나 **OOS에서 붕괴(과적합)** |
| 이익−주가 갭 | "성장 대비 덜 올랐나" | IS조차 \|t\|<1 |
| **SUE 서프라이즈** | "기대를 깼나"(정통 PEAD) | IS 전 임계 **음수**(SUE≥2.0 −5.76%) |

## 실패 원인 (영향 큰 순)

1. **유니버스의 정보 효율성 (근본 원인)** — 대형주는 애널리스트 커버리지·거래량이 많아 실적이 **발표 즉시 반영**된다. 발표 후 남는 드리프트가 거의 없고, 큰 서프라이즈(SUE≥2.0)는 오히려 60일간 되돌림(−5.76%). 신호 형태를 다 바꿔도 음성 → **문제는 신호가 아니라 유니버스**.

2. **알파 감쇠(alpha decay)** — PEAD는 1989년부터 공개·연구된 이상현상. 유동성 큰 시장일수록 차익거래로 소멸. 2016~2024 한국 대형주에서 약/음인 것은 자연스럽다. (`docs/research/04`)

3. **잘못된 초기 대용물(proxy)** — 처음엔 "YoY 성장 수준"을 신호로 썼는데, 이는 *서프라이즈*가 아니다(매년 20% 크는 건 시장이 이미 앎). SUE로 교정했으나 그래도 음성 → 대용물 오류는 **부차적 원인**이었고 근본은 유니버스.

4. **데이터 기간·표본 한계** — DART 재무는 2015년부터 → SUE는 워밍업 탓에 ~2017년부터만 계산. IS 표본이 작고(n≈7~20 at high threshold) 통계력이 약함. 2008·2011 위기 미포함. (`docs/research/07`)

5. **비용 구조** — 한국 개별주 매도세 0.18% + 슬리피지 ≈ 왕복 0.3%+. 설령 약한 드리프트가 있어도 비용이 먹는다. (`docs/research/05,06`)

6. **생존편향(낙관 상한)** — 대형주 10종목은 살아남은 종목. 즉 **낙관적 상한인데도** 엣지가 없었다 → 실제는 더 나쁠 것.

## 이 실패가 증명하지 *않는* 것

- "PEAD가 어디서도 안 통한다"가 **아니다.** PEAD는 학술적으로 **소형주에서 가장 강하게** 살아있다(정보 비효율). **소형주 PIT 유니버스(상폐 포함·유동성 필터)는 미검증.**
- 다만 소형주는 슬리피지·비용이 드리프트를 잠식하는 함정이 있어, *총* 드리프트가 있어도 *순* 엣지가 남을지는 별개 문제.

## 건진 자산 (재사용 가능)

- `data/dart_provider.py`, `data/earnings.py`: DART 데이터 계층 — PIT(접수일)·정정 최초값·연결재무·YoY·**SUE**(분기 순이익 시계열, Q4 도출).
- `backtest/event_study.py`: CAAR·룩어헤드 차단·복합/갭/SUE 신호·IS/OOS 하네스.
- `run_earnings*.py`: 단일/스윕/갭/SUE 오케스트레이터.
- 테스트 111개. → **향후 어떤 실적 신호·유니버스든 이 인프라로 바로 검증 가능.**

## 공정한 재시도에 필요한 것 (다음에 누군가 한다면)

1. **소형주 PIT 유니버스**: KRX/KIND 과거 상장·상폐 목록 ↔ corp_code 매핑(상폐 포함). corpCode.xml은 상폐사 stock_code가 빈값이라 외부 매핑 필수.
2. **유동성 필터 + 현실적 슬리피지**: 최소 거래대금, 동전주 제외, 소형주 슬리피지 상향.
3. **표본·기간 확대**: 수백 종목, 가능하면 2015년 이전(유료/ XBRL 원문)으로 통계력·위기 포함.
4. **SUE 윈저라이징**: 분모(과거 이익 표준편차)≈0 종목의 SUE 폭주(관측 max 110) 클램프.
5. **횡단면 랭킹 + 포트폴리오 엔진(모드 C)**: 절대 임계 대신 분기별 상위 decile, 동시보유·비용반영.

## 교훈

- **IS/OOS 분리가 거짓 발견을 막았다**: 복합 스윕에서 IS t=3.74 신호가 OOS에서 음수로 붕괴 — 분리 없었으면 자본을 넣었을 것.
- **신호를 계속 바꾸는 건 답이 아니다**: 3계열 음성 → 근본 변수(유니버스)를 의심해야 함. 신호 추가 탐색은 p-해킹.
- **싸게 죽이는 게 성공**: Phase 1 baseline과 동일하게, *돈 넣기 전에 코드로 "안 통함"을 확인*한 것이 이 작업의 가치다.
