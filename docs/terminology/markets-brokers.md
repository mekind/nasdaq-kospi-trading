# 시장 · 상품 · 브로커 (Markets, Instruments, Brokers)

## KOSPI (코스피)
한국 유가증권시장. 거래시간 09:00~15:30(한국 낮). 국내 거주자에게 계좌·세금·운영시간 마찰이 적다.

## NASDAQ (나스닥)
미국 기술주 중심 시장. 거래시간이 한국 밤(23:30~06:00). 세계에서 가장 효율적·경쟁적이라 엣지 발굴이 더 어렵다.

## ETF (Exchange Traded Fund, 상장지수펀드)
지수·자산을 추종해 주식처럼 거래되는 펀드. 개별 종목 위험을 분산.
- **KODEX 200 (069500)**: 코스피200 지수를 추종하는 대표 ETF. 우리 백테스트의 매매 대상.
- 참고: **주식형 ETF는 증권거래세 면제** → 비용 모델에서 거래세 0% 적용.

## 선물 (Futures)
미래 특정 시점에 사고팔기로 한 계약. 레버리지가 내장돼 위험이 크다(예: KOSPI200 선물).

## 코스피200 변동성지수 (V-KOSPI)
시장의 기대 변동성을 나타내는 "공포 지수". 급등하면 패닉을 의미 → 과매도 포착의 직접적 신호로 활용 가능.

## 증권거래세 (Securities Transaction Tax)
국내 주식 **매도 시** 부과(2024년 기준 약 0.18%). 주식형 ETF는 면제. 매도마다 자동 차감되며 거래가 잦을수록 누적 부담이 크다.

## 양도소득세 (Capital Gains Tax)
해외주식(예: 나스닥) 매매 차익에 부과(약 22%). 본인 신고 부담이 있어 국내 거주자의 미국주식 자동매매를 복잡하게 만든다.

## 위탁수수료 (Brokerage Commission)
주문 체결 시 증권사에 내는 수수료. 온라인 기준 대략 편도 0.01~0.015%(증권사별 상이). 우리 비용 모델 기본값 0.015%.

## KIS (한국투자증권 Open API)
코스피/해외주식을 다룰 수 있는 증권사 API. app key/secret → 토큰(24h) + 주문 시 hashkey 방식. 모의투자 계좌 제공. 공식 SDK는 없고 커뮤니티 라이브러리에 의존.

## Alpaca
미국 주식용 API 친화적 브로커. REST/WebSocket, 공식 Python SDK, 무료 페이퍼 트레이딩 제공. 단, 한국 거주자 가입 자격은 사전 확인 필요.

## FinanceDataReader (FDR)
한국/해외 시세를 무료로 받아오는 파이썬 라이브러리. 수십 년치 **일봉**을 쉽게 확보할 수 있어 우리 일봉 백테스트의 데이터 소스로 사용.
