# 용어집 (Terminology)

트레이딩 시스템을 만들며 알아야 할 용어를 카테고리별로 정리한다.
대화/설계 과정에서 다룬 개념들을 모아두고, 새 용어가 나오면 해당 파일에 추가한다.

## 목차

| 파일 | 내용 |
|------|------|
| [market-data.md](./market-data.md) | 시세 데이터 — OHLCV, 호가, 스프레드, 슬리피지, 유동성 등 |
| [indicators.md](./indicators.md) | 기술적 지표 — RSI, 이동평균(SMA) 등 |
| [strategy.md](./strategy.md) | 전략 개념 — 평균회귀, 모멘텀, 엣지, 레짐 등 |
| [backtest-stats.md](./backtest-stats.md) | 백테스트·통계 — 룩어헤드/생존편향, 기대값, 샤프, MDD 등 |
| [execution-infra.md](./execution-infra.md) | 체결·인프라 — 주문유형, HFT, 코로케이션, 페이퍼 트레이딩 등 |
| [markets-brokers.md](./markets-brokers.md) | 시장·상품·브로커 — 코스피, 나스닥, ETF, KIS, Alpaca, 세금 등 |

## 표기 규칙
- 각 용어: **국문 정의** + (필요시) **왜 중요한가 / 우리 프로젝트와의 연결**
- 영문 약어는 풀어서 함께 적는다.
