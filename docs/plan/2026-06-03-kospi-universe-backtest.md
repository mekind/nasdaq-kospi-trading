# 코스피 시총 상위 종목 RSI(2) 평균회귀 breadth 검증 설계

- **Status**: ✅ 구현·검증·전체실행 완료 (2026-06-03) — 83 테스트 통과, 시총 상위200 전체 백테스트. 결론: **엣지 없음(수익종목 ≈50%)**. PR 대기.
- **작성일**: 2026-06-03
- **브랜치(예정)**: `feature/kospi-universe-backtest`
- **선행**: [2026-06-03-data-extension.md](./2026-06-03-data-extension.md) (병합됨) — 동일 RSI(2) 전략·엔진 재사용

## 목표

지금까지 **지수 한 종목**으로만 본 RSI(2) 평균회귀가, **시장 전반(개별 종목들)에서도 통하는가**를
코스피 시총 상위 종목에 **각각 독립 적용**해 **결과 분포**로 검증한다. 룩어헤드·생존편향을 교정해
"부풀리지 않은" 답을 낸다.

핵심 질문: *전 종목에 돌렸을 때 **수익 난 종목 비율·기대값 분포**가 단순보유(buy&hold)·무작위 대비 의미 있는가?*

## 확정 결정 (스파이크 + analyst + 사용자 합의)

| 주제 | 확정 |
|------|------|
| 유니버스 | **pykrx 시점별 시총 상위 N(기본 200)**, **분기 리밸런싱**, 그 시점 상장 종목만 |
| 룩어헤드 | 없음 — "지금 시총"이 아니라 **각 분기 당시 시총**으로 멤버십 산정 |
| 생존편향 | 없음 — 분기 멤버십에 그 시점 상장 종목만 포함(상폐 종목은 폐지 전 분기까지 자동 포함, 이후 이탈) |
| 실행 | per-stock 독립(포트폴리오 아님), 기존 `BacktestEngine` 재사용 + **멤버십 마스킹 집계** |
| 비용 | 개별주 매도 증권거래세 **0.18%** (`CostModel(sell_tax_rate=0.0018)`) |
| 파라미터 | **고정**(RSI 2/10/70, 200일선, 5일) — 전 종목으로 과최적화 금지 |
| 단계화 | 표본(시총 상위 30) 먼저 파이프라인 검증 → 전체 |
| 의존성 | **pykrx 추가** (시점별 시총·종목 리스트용) |

## 핵심 설계 결정 (이유 포함)

### 결정 1 — 유니버스: pykrx 분기별 시총 상위 N + 시점별 멤버십

`pykrx`로 **각 분기말 기준 시총 상위 N 종목 명단**을 만든다(예 2014Q1, Q2 … 2026Q2). 명단은 분기마다 바뀐다.
- **룩어헤드 제거**: "오늘 시총 상위"가 아니라 "그 분기 당시 시총 상위"라 미래정보 미사용.
- **생존편향 제거**: 각 분기 명단은 그 시점에 **실제 상장돼 있던** 종목만 → 상폐 종목도 살아있던 분기엔 포함, 폐지 후 자동 이탈.

### 결정 2 — 멤버십 마스킹 집계 (엔진 불변의 핵심)

per-stock 독립 실행과 "시점별 멤버십"을 양립시키는 방법:
- 각 종목은 **전체 가용 이력으로 지표·시그널·백테스트**를 돌린다(SMA200 계산엔 과거가 필요하므로).
- 집계 시 **멤버십 분기 안에서 진입(entry_date)한 거래만 인정**하고, 멤버가 아니던 기간의 거래는 버린다.
- → 엔진(`BacktestEngine`)·전략·지표 **불변**. 멤버십 필터는 **aggregate 단계**에서 적용.
- 이유: 엔진을 건드리지 않으면서 "그 종목이 대형주였던 시기에 전략이 통했나"만 정확히 측정.

### 결정 3 — 개별주 비용 모델

`CostModel(sell_tax_rate=0.0018)` + 기존 수수료(0.015%)·슬리피지(5bp). ETF/지수(0%)와 달리 개별주는 세금이 성과를 깎는다. (costs.py에 `sell_tax_rate` 인자 존재 — 확인됨.)

### 결정 4 — 데이터 무결성 가드 (analyst H4/M4)

- **부분/실패 데이터는 캐시 저장 금지**: fetch 0행·짧은 이력·예외는 캐시에 안 남겨 다음 실행 오염 방지.
- **per-symbol try/except + 사유별 스킵 카운트**: `network` / `empty` / `short_history` / `exception`. 한 종목 실패가 전체 러너를 멈추지 않게.
- **최소 이력 임계 = 250봉**(SMA200 + RSI + 여유) 미만 종목은 스킵 카운트. (strategy는 SMA200 NaN이면 진입 안 하지만, 모수 명확화 위해 명시적 제외.)
- 레이트리밋 대비 **요청 간 지연·재시도(백오프)** 정책.

### 결정 5 — 집계 통계의 함정 차단 (analyst H3/M1/M2)

- **중앙값·사분위 우선**. 평균은 상폐·단기 종목의 극단 CAGR에 오염되므로 winsorize 또는 outlier 플래그 후 보조 지표로만.
- **원화 `total_pnl` 횡단 합산 금지** — 종목별 1,000만원 독립이라 합산은 무의미(동시보유 아님). 1차 지표는 **종목별 수익률(%)·기대값 부호**.
- **상폐 종목 vs 생존 종목 분포를 분리 리포트** — 상폐 종목 마지막 봉(정리매매 비정상가) 꼬리를 분리해 본다.
- **n_trades=0(매매 미발생) 종목 처리 양쪽 보고**: "거래한 종목 중 수익 %"와 "전체 중 수익 %"를 **둘 다** 출력(분모 명시).
- **출력 가드**: `per_stock_results.csv`·콘솔에 "동시보유 아님 — 원화 합산 무의미, 전략 일반성 측정" 고정 헤더.

### 결정 6 — 수정주가 검증 스캐너 (analyst M3)

개별주 액면분할/권리락 미반영 시 가격 점프가 가짜 RSI 시그널을 만든다. 검증 산출물로:
- 알려진 분할 종목(삼성전자 2018-05 50:1 등) 전후 종가비 자동 점검(≈1.0 수정주가 / ≈1/N 미수정).
- 전 종목 **일일 수익률 |Δ| > 30% 점프 스캐너** → 분할/권리락 의심 종목 플래그·리포트.

### 결정 7 — 벤치마크·crash 버킷 (analyst L2/M1)

- **종목별 buy-and-hold 수익률 분포**를 동시 산출 → 전략 분포와 비교(귀무가설 기준선).
- crash 기간을 데이터 범위(2014~)에 맞게 **2018·2020·2022**로 재정의, 횡단 집계는 `return_pct` 분포 기반(원화 합산 아님).

## 데이터 흐름

```
market_cap.py: pykrx로 분기말마다 시총 상위 N → {분기: [종목...]} 멤버십
  → universe.py: 전 분기 멤버 합집합 = fetch 대상 종목 + 종목별 멤버십 기간
  → run_universe.py: 각 종목
       FdrProvider.load_daily(캐시·무결성·스킵) → RSI(2)·SMA200 시그널
       → BacktestEngine(개별주 비용) → trades/equity (실패 종목 사유별 카운트)
  → aggregate.py:
       멤버십 분기 내 진입 거래만 인정 → 종목별 지표(수익률·기대값·MDD)
       + 종목별 buy&hold 벤치마크 + crash(2018/2020/2022) 횡단(% 기반)
       → 분포 요약(중앙값/사분위, 거래종목중 수익%, 전체중 수익%, 상폐/생존 분리)
  → 콘솔 요약 + per_stock_results.csv(+가드 헤더) + 분할 의심 종목 리포트
```
