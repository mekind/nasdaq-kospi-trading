## 스파이크 결과 (2026-06-03) — 설계 결정 확정

작업①(데이터 소스 실측)을 먼저 수행해 아래를 확정했다. **이로써 pykrx·신규 provider는 불필요**해졌고, 대신 **데이터 결측 처리 버그**가 드러나 그 수정이 실제 작업이 되었다.

| 항목 | 실측 결과 |
|------|-----------|
| FDR `KS200` + 명시적 `start='1990-01-01'` | 1990-01-03 ~ 2026, **9396봉** |
| **실사용 가능 구간(OHLC 전부 존재)** | **1995-01-03 ~ 2026, 7925봉** — 1997 IMF·2000 닷컴·**2008 GFC**·2020·2022 포함 |
| 1990~1995-01 (1471봉) | open/high/low = NaN(종가만) → 체결 불가, **버려야 함** |
| FDR `069500`(ETF) | 여전히 2014~ 3000봉 고정 (FDR 소스 한계, 이번 대상 아님) |
| pykrx 의존성 | **불필요** — FDR로 목표(2008 포함) 달성 |

**확정 결정**
- **데이터 소스**: 기존 `FdrProvider`로 `KS200`(KOSPI200 지수) + 명시적 `start`. 신규 의존성 0, 신규 provider 0.
- **연구 대상**: KOSPI200 지수(사용자 선택). ETF 비용 현실성 교차확인은 069500이 2014~뿐이라 별도 후속으로 분리.

**드러난 버그 (이번 작업의 핵심)**
- 장기 데이터에 OHLC 결측 봉이 섞이면, 엔진이 `open`(체결가)으로 `qty = cash/open`을 계산할 때 `open=NaN` → 포지션·자산곡선 전체가 **NaN으로 오염**(최종자본 NaN, metrics 0). 실측에서 재현됨.
- 원인: `FdrProvider.load_daily`가 `close`에 대해서만 `dropna`. `open/high/low` 결측 봉이 통과함.

## 목표

Phase 1 백테스트의 **데이터 한계(FDR이 069500을 2014~만 반환, ~3000봉)** 를 해소해
**2008 금융위기를 포함한 장기 일봉**을 확보하고, baseline 평균회귀 전략을 그 위에서 다시 돌려
*"엣지 없음 / 꼬리 위험"이라는 Phase 1 결론이 폭락장을 포함해도 유지되는가*를 재검증한다.

핵심 질문: **2008을 데이터에 넣으면 결론이 바뀌는가, 더 나빠지는가?** (꼬리 위험이 코로나 1회보다 큰지)

## 핵심 설계 결정 (이유 포함)

### 결정 1 — 데이터 소스: KRX(pykrx) 우선, FDR `KS200` 폴백

FDR이 ETF(069500)를 2014~만 주는 게 확인된 제약이므로, 더 긴 시계열을 주는 소스가 필요하다.
후보를 **작업 1(실측 스파이크)에서 실제로 받아보고** 확정하되, 사전 평가는 다음과 같다:

| 후보 | 기대 범위 | 장점 | 단점/리스크 |
|------|-----------|------|-------------|
| **pykrx (KRX 공식)** | 지수 1990~, ETF 2002~ | 공식·무료, OHLCV+거래량, 지수/ETF 모두 | 의존성 추가, KRX 응답 포맷/레이트리밋 |
| **FDR `KS200` 지수** | 1990~ | 의존성 그대로, 코드 최소 변경 | 지수라 거래량·체결 의미 다름, 수정주가 불명확 |
| FDR 069500 (현행) | 2014~ | 현 코드 | **2008 미포함 = 목표 미달** |

→ **권장: pykrx로 069500(ETF) 2002~ 확보.** 단, ETF가 2002~ 전체를 못 주면
**KOSPI200 지수(1028 / KS200)를 1990~ 로 받아 폭락 검증용 장기 시계열로 사용**한다.
(지수는 실거래 대상은 아니나 "평균회귀 엣지·꼬리 위험"이라는 **연구 질문에는 더 긴·깨끗한 시계열**이라 적합.)

### 결정 2 — 지수 vs ETF 역할 분리

- **엣지/꼬리 위험 연구** → 장기 지수(KS200, 1990~)로 2000닷컴·2008·2020·2022를 모두 통과시켜 본다.
- **실매매 현실성(비용·체결)** → ETF(069500) 2002~ 로 별도 확인.
- 두 결과를 나란히 비교해 "지수 엣지가 ETF 비용을 통과하고도 남는가"를 본다.

### 결정 3 — 기존 인터페이스/엔진 불변

전략·백테스트 엔진·비용·지표는 **그대로 재사용**한다. 이번 작업은 **데이터 레이어만 확장**한다.
표준 스키마(DatetimeIndex + open/high/low/close/volume, float)를 동일하게 산출해
하위(strategy→engine→metrics)가 변경 없이 동작하게 한다.

### 결정 4 — 수정주가/배당 처리 명시

ETF는 분배금 재투자 여부에 따라 시계열이 달라진다. 소스가 수정주가를 주는지
작업 1에서 확인하고, **미수정이면 그 사실을 결과에 라벨링**한다(Phase 1처럼 "데이터 한계" 주석).

## 데이터 흐름

```
pykrx로 069500(ETF, 2002~) 또는 KS200(지수, 1990~) 일봉 fetch
  → 표준 스키마 정규화(소문자 OHLCV, float, DatetimeIndex 오름차순, close NaN 제거)

```

## 비용/리스크 고려

- **네트워크 의존**: FDR이 외부에서 시세 fetch → parquet 캐시로 재실행 비용 최소화.

## 재실행 결과 (KS200 지수, 1995-01-03 ~ 2026-06-02, 7925봉)

> ⚠️ **지수(KS200) 백테스트**다. KODEX 200 ETF는 FDR에서 2014~뿐이라 장기 검증 대상에서 제외했고,
> 1995~2002 구간은 ETF 상장 전이다. 따라서 이 수치는 **연구용(엣지·꼬리 위험)** 이며 실매매 비용·체결과는 별개다.

### Phase 1 ↔ Phase 2 비교

| 지표 | Phase 1 (KODEX 069500, 2014~, 3000봉) | **Phase 2 (KS200 지수, 1995~, 7925봉)** |
|------|--------------------------------------|------------------------------------------|
| 총수익률 | +5.98% | **+177.23%** |
| CAGR | 0.49% | **3.30%** |
| MDD | -20.74% | -18.44% |
| 샤프 | 0.11 | **0.45** |
| 거래 | 62회, 승률 56.5%, 손익비 0.86, 기대값 +9,641 | 202회, 승률 61.9%, 손익비 1.01, 기대값 **+87,736** |
| 2008 GFC | (데이터 없음) | **0거래** — 급락 내내 종가<200MA, 추세필터가 전량 회피 |
| 2020 COVID | 1거래 -597,615 (자본 ~6%) | 1거래 **-1,166,221 (자본 ~12%)** |

### 해석 (정직한 결론)

1. **데이터 확장 목표 달성**: 2008(및 1997·2000) 포함 31년으로 검증 기반이 넓어졌다. Phase 1의 "2014~ 한계" 해소.
2. **추세필터가 느린 약세장을 구조적으로 회피한다**: 2008 GFC 급락 구간엔 한 건도 진입하지 않았다(시장 밖). 꼬리 위험이 "안 터진" 게 아니라 **안 들어가서 피한 것**.
3. **그러나 빠른 급락(2020)엔 여전히 취약**: 고점 부근(200MA 위)에서의 급락은 필터를 통과해 진입 → 전액투입(all-in) 탓에 **단일 거래로 자본 ~12% 손실**. 음의 꼬리 위험은 잔존.
4. **지표는 Phase 1보다 나아 보이나 과신 금지**: ① 지수≠ETF(실매매 비용·추적오차 미반영), ② CAGR 3.30%는 단순보유 대비 열위 가능성 높고 예금 수준, ③ 시장 노출 시간이 짧아 절대수익이 낮다. → **아직 "돈 넣을 엣지"는 아님.** 다음은 ETF 비용 반영·포지션 사이징(2020 꼬리 대응)·단순보유 벤치마크 비교.
