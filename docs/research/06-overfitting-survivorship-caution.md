# 사례 06 — 과최적화·생존편향 일반 함정 (경고 정리)

- **성격**: 메타 분석 / 실패 원인 정리
- **대상 시장**: 한국 주식·선물 전반
- **정리일**: 2026-06-02

## 요약

성공 사례가 노출되는 만큼, 개인 퀀트의 **대다수는 수익을 내지 못한다**는 것이 업계의 솔직한 진단이다. 실패의 구조적 원인은 크게 과최적화, 알파 소멸, 생존편향, 심리적 지속 실패 네 가지다.

## 실패 원인 4가지

### 1. 과최적화 (Overfitting)
- 퀀트 연구를 하다 보면 어느 순간 "인생 역전" 같은 대박 전략을 만나게 된다. y=x² 곡선처럼 수익이 기하급수적으로 우상향하고 변동성도 거의 없는 "완벽한" 백테스트.
- 이는 과거 데이터에 파라미터를 끼워 맞춘 결과일 가능성이 높다. **완벽할수록 의심하라.**

### 2. 알파 소멸 (Alpha Decay)
- 로직이 공개된 전략은 먹을 파이가 급감한다. 퀀트 책이 유행하며 전략 접근성이 높아진 만큼 초과수익은 빠르게 사라진다. (사례 04·05 참조)

### 3. 생존편향 (Survivorship Bias)
- 성공한 소수만 인터뷰·책·강의로 노출되고, 실패한 다수는 조용히 사라진다. 보이는 사례만으로 기대수익을 추정하면 과대평가된다.

### 4. 심리적 지속 실패
- 퀀트는 자기 전략을 믿고 **장기 투자**해야 효과를 본다. 그러나 개인은 주가 등락과 드로다운(손실 구간)을 견디지 못하고 중간에 전략을 바꾸거나 이탈한다.

## 백테스트 함정을 줄이는 체크리스트

- [ ] In-sample / Out-of-sample 분리 검증을 했는가
- [ ] 여러 시기·시장 국면(레짐)에서 강건한가
- [ ] 거래비용·슬리피지·세금·상장폐지 편향을 반영했는가
- [ ] 소형주 유동성 한계(체결 가능성)를 고려했는가
- [ ] 파라미터 수가 과도하지 않은가 (단순할수록 강건)
- [ ] 드로다운을 실제로 견딜 수 있는 자금/심리 구조인가
