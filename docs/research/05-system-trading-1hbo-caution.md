# 사례 05 — 1HBO 시스템 트레이딩 (성공→실패 전환, 교훈)

- **성격**: 단기 시스템 트레이딩 (선물), 알파 소멸 실패 사례
- **대상 시장**: 국내 선물 (시스템 트레이딩 커뮤니티)
- **시기**: 약 20여 년 전 (2000년대 초반 추정)
- **정리일**: 2026-06-02

## 요약

1HBO(1 Hour Break Out, 1시간 돌파) 시스템은 과거 국내 선물 시스템 트레이더들 사이에서 유행한 단기 전략이다. 초기에는 수익을 냈으나, 책과 시스템 트레이딩 솔루션을 통해 유명해지고 심지어 **솔루션에 기본 전략으로 탑재된 이후에는 수익은커녕 손실만 내는 전략**으로 전락했다.

## 전개 타임라인

| 단계 | 결과 |
|------|------|
| 초기 (소수만 사용) | 수익 발생 |
| 책·커뮤니티로 확산 | 알파 축소 시작 |
| 솔루션 기본 탑재 | 손실 전략화 |

## 시사점

- **공개된 전략 = 죽은 전략**: 단기 가격 패턴(돌파 등)에 기반한 전략은 참가자가 늘면 즉시 효율화되어 알파가 사라진다. 책으로 유명해진 전략일수록 위험.
- **단기 시스템 트레이딩의 구조적 한계**: 거래비용·슬리피지·세금이 빈번한 매매에서 누적되어, 표면 수익이 실제로는 마이너스가 되기 쉽다.
- **성공 사례(01~03)와의 대비**: 장기 팩터 퀀트는 "지속"으로 이기지만, 단기 패턴 트레이딩은 "선점"으로만 이긴다 — 선점 우위는 공개되는 순간 끝난다.
