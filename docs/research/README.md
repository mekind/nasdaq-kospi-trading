# 개인 퀀트 트레이딩 성공/실패 사례 정리 (코스피·코스닥)

> 정리일: 2026-06-02
> 목적: 개인 투자자가 한국 시장(코스피/코스닥)을 대상으로 퀀트·시스템 트레이딩으로 실제 돈을 번 사례와 그 한계를 날짜·출처와 함께 기록한다.

## 한 줄 결론

검증 가능한 **장기 팩터 기반 퀀트(저평가 + 소형주 + 모멘텀/퀄리티)** 로 코스피를 초과하는 성과를 낸 개인 사례는 존재한다. 다만 "백테스트 대박", "단기 시스템 트레이딩 일확천금" 류는 과최적화·알파 소멸·생존편향으로 대부분 재현되지 않는다.

## 읽는 순서 권장

1. 성공 사례(01~03)로 "현실적으로 가능한 성과 수준"을 잡는다.
2. 04~06으로 그 성과가 왜 쉽게 무너지는지(알파 소멸·과최적화·생존편향) 이해한다.

## 면책

아래 수치는 모두 출처 기사/자료의 **백테스트 또는 당사자 주장**이며, 미래 수익을 보장하지 않는다. 투자 판단의 근거가 아닌 사례 연구용 기록이다.
